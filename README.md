# TensorFlow.js 学习项目

这是一个基于 TensorFlow.js 的机器学习项目，包含两个深度学习示例：汽车油耗预测和 AI 英文名字生成器。

## 📋 项目简介

本项目使用 TensorFlow.js 在浏览器中运行机器学习模型，展示了两种不同的深度学习应用：

1. **汽车油耗预测**（`index1.html` + `main.ts`）- 基于马力预测汽车的燃油效率（MPG）
2. **AI 英文名字生成器**（`index.html` + `main2.ts`）- 使用 LSTM 神经网络生成创意英文名字

## 🎯 功能特性

### 1. 汽车油耗预测（MPG 预测）

**访问方式**: 打开 `index1.html`

**功能说明**:

- 使用深度神经网络预测汽车的燃油效率（Miles Per Gallon）
- 基于汽车的马力（Horsepower）作为输入特征
- 实时可视化训练过程和预测结果

**模型架构**:

```
输入层 (1个特征)
  ↓
Dense层 (50个神经元, ReLU激活)
  ↓
Dense层 (30个神经元, ReLU激活)
  ↓
Dense层 (10个神经元, ReLU激活)
  ↓
输出层 (1个输出值)
```

**训练参数**:

- 优化器: Adam (学习率 0.001)
- 损失函数: Mean Squared Error
- 批次大小: 32
- 训练轮数: 32 epochs

### 2. AI 英文名字生成器

**访问方式**: 打开 `index.html`（默认页面）

**功能说明**:

- 使用 LSTM 神经网络学习英文名字的模式和结构
- 训练完成后自动生成 20 个创意英文名字
- 支持自定义首字母生成（通过浏览器控制台）

#### 🧠 工作原理详解

AI 英文名字生成器采用了**字符级语言模型**（Character-level Language Model）的方法，通过深度学习学习英文名字的统计规律和模式。

**核心思想**:

- 将名字生成问题转化为**序列预测问题**
- 给定前面 N 个字符，预测下一个字符是什么
- 通过逐字符预测，最终生成完整的名字

**具体流程**:

1. **数据准备阶段**

   ```
   原始名字: "emma"
   添加结束标记: "emma$"

   创建训练样本（序列长度=3）:
   输入序列          →  输出字符
   ['e','m','m']    →  'a'
   ['m','m','a']    →  '$'
   ```

   通过滑动窗口，一个名字可以生成多个训练样本。5000+ 个名字最终产生数万个训练样本。

2. **One-Hot 编码**

   每个字符被转换为一个 27 维的向量（26 个字母 + 1 个结束标记）:

   ```
   'a' → [1,0,0,0,...,0]  (第1位为1)
   'b' → [0,1,0,0,...,0]  (第2位为1)
   '$' → [0,0,0,0,...,1]  (第27位为1)
   ```

3. **LSTM 神经网络**

   LSTM（长短期记忆网络）是一种特殊的循环神经网络，非常适合处理序列数据：

   - **记忆能力**: LSTM 可以记住之前见过的字符，理解字符之间的依赖关系
   - **模式学习**: 学习英文名字的常见模式，如：
     - 元音辅音的交替规律（如 "sarah"）
     - 常见字母组合（如 "th", "ch", "er"）
     - 名字的长度分布
     - 开头和结尾的字母偏好

   **网络层次功能**:

   ```
   LSTM层 (128单元)    → 捕捉字符序列的长期依赖关系
   Dense层 (64神经元)  → 提取高级特征
   Dense层 (32神经元)  → 进一步特征抽象
   Dropout层 (25%)     → 防止过拟合，提高泛化能力
   输出层 (27神经元)   → 预测下一个字符的概率分布
   ```

4. **训练过程**

   模型通过反向传播算法不断调整参数：

   ```
   损失函数 = 预测概率分布 与 实际字符 之间的差异
   目标: 最小化损失函数
   ```

   经过 16 轮训练，模型逐渐学会：

   - 哪些字符组合更常见
   - 名字的典型长度
   - 何时应该结束名字生成

5. **名字生成过程**

   训练完成后，生成新名字的流程：

   ```python
   # 伪代码示例
   name = "j"  # 随机选择一个起始字母

   while name 未结束:
       # 1. 获取最后3个字符作为输入
       sequence = name[-3:]  # 例如 "joh"

       # 2. 转换为 One-Hot 编码
       input_tensor = one_hot_encode(sequence)

       # 3. 模型预测下一个字符的概率
       probabilities = model.predict(input_tensor)
       # 例如: [0.01, 0.05, 0.02, ..., 0.3, ...]
       #       (概率最高的可能是 'n')

       # 4. 根据概率分布随机采样（引入创造性）
       next_char = sample(probabilities)

       # 5. 如果是结束标记，停止生成
       if next_char == '$':
           break

       # 6. 将新字符添加到名字中
       name += next_char  # "john"

   return name  # "john"
   ```

6. **温度参数（Temperature）**

   控制生成的随机性和创造性：

   ```
   低温度 (0.5)  → 更保守，生成类似训练数据的名字
   中温度 (1.0)  → 平衡，既像真实名字又有创意
   高温度 (1.5)  → 更随机，可能生成奇特的名字

   概率调整公式: P'(i) = P(i)^(1/T) / Σ(P(j)^(1/T))
   ```

**为什么这种方法有效?**

- **统计学习**: LSTM 从大量真实名字中学习到了隐含的统计规律
- **上下文感知**: 通过序列建模，模型理解字符之间的上下文关系
- **创造性**: 采样机制引入随机性，而不是总是选择概率最高的字符
- **质量控制**: 通过长度惩罚和温度调节，确保生成的名字既真实又有创意

**示例: 模型如何生成 "Mira"**

```
1. 起始: 'm'
   模型输入: ['m','m','m'] (填充)
   预测概率: {'i':0.3, 'a':0.25, 'e':0.2, ...}
   采样结果: 'i'  →  name = "mi"

2. 继续: "mi"
   模型输入: ['m','m','i']
   预测概率: {'r':0.35, 'c':0.2, 'k':0.15, ...}
   采样结果: 'r'  →  name = "mir"

3. 继续: "mir"
   模型输入: ['m','i','r']
   预测概率: {'a':0.4, 'i':0.2, 'o':0.15, ...}
   采样结果: 'a'  →  name = "mira"

4. 继续: "mira"
   模型输入: ['i','r','a']
   预测概率: {'$':0.5, 'n':0.2, 'h':0.1, ...}
   采样结果: '$'  →  结束生成

最终名字: "Mira" ✓
```

**模型架构**:

```
输入层 (序列长度: 3, 词汇量: 27)
  ↓
LSTM层 (128个单元, L2正则化)
  ↓
Dense层 (64个神经元, ReLU激活, L2正则化)
  ↓
Dense层 (32个神经元, ReLU激活, L2正则化)
  ↓
Dropout层 (25% 丢弃率)
  ↓
输出层 (27个字符, Softmax激活)
```

**训练参数**:

- 优化器: Adam (学习率 0.002)
- 损失函数: Categorical Crossentropy
- 批次大小: 256
- 训练轮数: 16 epochs
- 验证集比例: 15%
- 训练样本: 基于 5000+ 个英文名字

**高级使用**:

训练完成后，可以在浏览器控制台使用以下命令：

```javascript

await pn("j"); // 生成以 'j' 开头的名字
await pn("a"); // 生成以 'a' 开头的名字

// 访问模型对象

```

## 📊 性能优化

### 名字生成器优化

项目对 LSTM 名字生成器进行了多项性能优化：

1. **张量构建优化**: 使用 Float32Array 直接构建张量，比 buffer.set 快 10 倍
2. **初始化器优化**: 使用 glorotUniform 和 heNormal 替代默认的 orthogonal 初始化器
3. **异步 API**: 使用 `data()` 替代 `dataSync()` 避免 WebGPU 性能警告
4. **内存管理**: 使用 `tf.tidy()` 自动管理中间张量的内存
5. **批次大小优化**: 增大批次大小到 256 加快训练速度
6. **长度控制**: 限制生成名字的最大长度，提高质量

### 训练加速

- 固定词汇表大小（27 个字符：a-z + 结束标记）
- 移除不必要的开始标记，简化序列结构
- L2 正则化防止过拟合
- 15% 验证集监控训练效果
